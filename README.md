## <img src=".github/assets/icon-sparkle.svg?v=6" width="24" align="middle"> The Arsenal

Welcome to my personal dump of desktop utilities and automation tools. This is where I throw the things I build when I get too lazy to do repetitive tasks manually. 

Instead of doing actual work, I spent hours building these tools so that computers can do the work for me. Feel free to browse, but remember: this is my personal toolkit, so don't expect enterprise-grade customer support when something breaks.

### 📦 [Github Build Release](./Github-Build-Release)
Tired of typing out release notes like a 1990s data entry clerk? This Electron app takes your code, uses AI to magically generate release notes, and pushes the release straight to GitHub. Because your brain cells are better spent elsewhere.

### 💾 [Backup Studio](./backup_projects)
An Electron app that violently grabs your projects and forcefully syncs them to Dropbox. Don't be that guy who cries on Reddit because his SSD died and he didn't commit for 3 weeks. Set it, forget it, and let it save your digital life.

### 🤖 [Discord Bot & Dashboard](./discord_bot)
A heavy-duty Discord bot that plays music, handles idle tasks, and moderates your chaotic server before it descends into anarchy. It even comes with a full Web Dashboard, because typing commands in a chat box is too much effort.

### 🖱️ [Autoclicker Premium](./autoclicker_premium)
A highly configurable auto-clicker for Windows. Perfect for pretending you are actively working, destroying your enemies in a game, or testing APIs to the breaking point. Use responsibly (or don't, I'm not your boss).

## <img src=".github/assets/icon-key.svg?v=6" width="24" align="middle"> How to use

These projects are independent. To run or build any of them:
1. cd into the project directory (e.g. cd backup_projects).
2. Run 
pm install.
3. Check the internal files or package.json for the build scripts (usually 
pm run dev or 
pm run build).
4. If it requires API keys (like Discord or OpenAI), create a .env file and put them in. If you don't know how, you probably shouldn't be running this.
