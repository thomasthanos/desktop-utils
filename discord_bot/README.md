## <img src="https://raw.githubusercontent.com/thomasthanos/desktop-utils/assets/discord_bot/.github/assets/icon-sparkle.svg?v=979" width="24" align="middle"> What it is

A heavy-duty Node.js bot that plays music, handles idle tasks, and babysits your chaotic Discord server. Comes with a full web dashboard because typing chat commands feels like we're back in 2012.

### Features

- **Web Dashboard for lazy admins**
- **Music Player**
- **Moderation tools for toxic members**
- **Database Sync & Backup**
